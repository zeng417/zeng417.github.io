## 开始

你好，欢迎来到我的博客！

这是我用 Jekyll + GitHub Pages 搭建的个人博客。整个博客是开源的，代码托管在 GitHub 上。

## 为什么要写博客

写博客有很多好处：

1. **记录学习过程** —— 把学过的知识整理成文，加深理解
2. **倒逼自己输入** —— 为了输出，会主动去学习新东西
3. **建立个人品牌** —— 让更多人认识你
4. **帮助他人** —— 你踩过的坑，也许正好是别人正在搜的

## 技术栈

这个博客使用的技术：

- **Jekyll** —— 静态站点生成器
- **GitHub Pages** —— 免费托管
- **Markdown** —— 写作语法
- **SCSS** —— 样式管理

## Markdown 语法示例

文章用 Markdown 语法编写，非常简单：

```markdown
# 标题
## 小标题

**加粗**、*斜体*、~~删除线~~

- 列表项一
- 列表项二

[链接](https://github.com)
```
